About this data

Range (Gm) = tank / SCU per Gm. Sources: ships, modules; prices from UEX (lowest purchase price, community data). Only purchasable ships, only drives of matching size.

Flight time is a modelled route (undock, NAV, then QT jumps of 60 Gm, 3 Gm and 30 Gm with 30 km approaches) based on the API acceleration and speed values, not a measured in-game time; the assumptions are described in the README.

Click a column header to sort (click again: toggle direction). Shift+click adds another column as the next sort key. The price limit uses the total price (ship + drive); for a stock drive the ship price is used.
